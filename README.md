💸 Expense Tracker
===
### *A Full-Stack Personal Expense Management System*

About
---
**Expense Tracker** is a full-stack desktop application that helps users manage and analyze their daily expenses. It provides a structured way to record, categorize, and visualize spending, making personal finance tracking more efficient and intuitive.

The application integrates a JavaFX-based user interface with a Spring Boot backend and MySQL database to simulate a real-world multi-user system.

Purpose
---
Tracking expenses manually can be inconsistent and difficult to manage over time. This project provides a centralized platform where users can monitor their spending, gain insights, and make informed financial decisions.

Features
---
* User authentication (login and signup)
* Add, edit, and delete expenses
* Categorize expenses (food, travel, bills, etc.)
* Track expenses over time
* Visualize spending through charts and summaries
* User-specific data management
* Full CRUD operations for expense records

How It Works
---
Users create an account or log in, add their expenses with relevant categories and details, and view their spending patterns over time. The system processes and stores data securely, while visualizations help users understand their financial habits.

Outcome
---
The application provides a structured and interactive way to manage personal finances, combining backend logic, database design, and user interface into a complete end-to-end system.
